# 수정 및 검증 결과

검증일: 2026-09-15 · 원본 https://pickcare.co.kr/ · 복제본 http://localhost:3000/

## 이번 수정

- 빠졌던 2D 캐릭터5종 추가. 기존1종을 포함한6종 캐릭터 퍼레이드 구현.
- 180초 비활동 후 나타나는 캐릭터,4초 유지 및 활동 시 닫기 구현.
- 원본의 새해·세계 동물의 날·크리스마스 인사와 컨페티 구현.
- 원본 움직이는 로딩 GIF 추가.
- 부드러운 스크롤 엔진을 원본과 같은 Lenis1.3.15로 고정.
- 새로고침 후 이전 스크롤 위치와 시작 애니메이션이 어긋나는 문제 수정.
- 본문 바로가기 포커스 스타일 복원. 로그인 버튼을 확인된 원본 로그인 화면으로 연결.

## 검증

- npm run build 통과. TypeScript 검사 통과.
- 기존 캐릭터·본문 이미지18개의 SHA256이 새로 받은 원본과 모두 일치.
- 데스크톱 히어로·가이드·카드·서비스, 모바일 히어로·서비스·배너를 원본과 대조.
- 모바일에서 원본과 복제본 모두 코나미 키 입력에 따라6종 캐릭터 생성 및 이미지 로딩 확인.
- 새 프로덕션 세션에서 콘솔 error0건 확인.
- 실제 컴포넌트의 제어 가능한 시계 테스트12개 통과: 유휴180초/표시4초,5종 입력 재설정, 코나미6초,3종 기념일5초/세션 중복 방지. DOM/CSS·Framer 시각적 보간은 이 테스트 범위 밖입니다.
- 스크롤Y2930에서 새로고침한 뒤0으로 정상 시작하는 것 확인.
- 페이지 로딩 fallback이 실제 브라우저 접근성 트리에 나타나는 것 확인.

## 픽셀 비교의 범위

자동으로 바뀌는 질문 문구, 움직이는 화살표, 스크롤 방향에 따라 달라지는 헤더와 스크롤바를 제외한 아래 고정 영역은 캡처한 상태에서 RGB 픽셀 차이0개였습니다. 전체 사이트나 모든 애니메이션 프레임에 대한100% 수치를 뜻하지 않습니다.

## 남아 있는 범위 제한

홈페이지 프런트엔드 복제입니다. AI 서버·실제 회원 인증·데이터베이스·다른 경로의 화면은 구현하지 않았으며 관련 버튼은 원본 서비스로 이동합니다. 기념일 효과는 원본 코드를 대조했으며 날짜별 상태 로직을 제어 가능한 시계로 검증했지만 브라우저 날짜를 변경한 화면 검증은 하지 않았습니다. 운영체제·프레임 속도·모든 화면 크기에서의 모든 순간까지100% 일치를 보증하지는 않습니다.
