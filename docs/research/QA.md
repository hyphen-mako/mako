## 알려진 차이·검증 범위

- 홈페이지 프런트엔드 범위입니다. 다른 경로는 원본 서비스 링크로 연결합니다.
- 질문 제출 URL 생성 로직은 원본과 동일하고 목적지는 원본 `/chat`입니다. 실제 AI 질문 전송은 테스트하지 않았습니다.
- 로그인 선택 UI는 복제했으며 버튼은 원본 홈페이지로 이동합니다. Kakao/Apple OAuth와 사용자 인증은 구현하지 않았습니다.
- 서버/회원 데이터/실시간 AI/계정별 화면은 구현하지 않았습니다.
- 호버·스크롤·타이머의 핵심 수치를 원본 공개 코드에서 보존했지만 다른 프레임 속도, 운영체제, 모든 시점의 픽셀 일치를 보증하지 않습니다.
- 원본 CSS에 있는 레이아웃 특징(예: 태블릿 히어로의 넓은 빈 공간)도 그대로 유지했습니다.
- 원본 홈페이지의 분석·추적 코드는 포함하지 않았습니다.
