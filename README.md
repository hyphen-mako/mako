# PiCKCARE 홈페이지 복제

원본: https://pickcare.co.kr/ · 확인일: 2026-09-15

## 실행

Node.js 20.9 이상 권장. 최초 실행:

```sh
npm ci --cache ./work/npm-cache
npm run build
npm start
```

http://localhost:3000 에서 확인합니다. 수정 중에는 `npm run dev`를 사용합니다.

## 구현

- Next.js + React + Framer Motion + Lenis
- 히어로, 반려생활 가이드, 서비스 소개, 브랜드 배너, 푸터의 5개 구간
- 헤더·튜토리얼·질문창을 포함한 9개 화면 컴포넌트와 로딩 화면, 선택형 성능 측정 도구, 11개 명세
- 원본 이미지, SVG, Pretendard·Remix Icon 폰트 로컬 제공
- 캐릭터 등장·말풍선, 워터마크 바운스, 부드러운 스크롤, 카드 등장·회전·확대
- 서비스 카드 스크롤/클릭 전환, 질문 문구 자동 변경, 질문 버튼 확장
- 3분 대기 시 캐릭터 등장, 코나미 코드 6종 캐릭터 퍼레이드, 기념일 인사·컨페티
- 원본 움직이는 로딩 GIF 및 Lenis1.3.15 스크롤 엔진
- 첫 방문 3단계 튜토리얼, 닫기·단계 선택·다시 보지 않기 저장
- 모바일 메뉴·하위 메뉴, 가이드 카드 좌우 드래그, 모바일/태블릿 레이아웃

## 애니메이션 성능 개선

연속 스크롤 값의 페이지 전체 재렌더링을 줄이고, 애니메이션 프레임 루프를 해제하도록 수정했습니다. 같은 스크롤 구간의 전체 렌더링은 46회에서19회로 약59% 감소했습니다. 프레임 속도59% 향상을 의미하지 않습니다. 원본 등장 시간·카드 회전·전환 속도는 유지했습니다. 검증 자료는 `docs/research/performance/`에 있습니다.

## 검증 및 범위

`npm run build`, `npx tsc --noEmit` 통과. 1440px 데스크톱과 390px 모바일의 주요 히어로 요소 좌표·크기를 원본과 비교했습니다. 768px 태블릿에서도 주요 요소 좌표·크기가 일치했습니다. 상세 결과는 `docs/research/QA.md`에 있습니다.

이 프로젝트는 제공된 URL의 **홈페이지 프런트엔드** 복제입니다. AI 서버, 회원 인증, 데이터베이스와 다른 페이지는 복제하지 않았습니다. 질문·서비스 링크는 원본 사이트로 이동하며 로그인 버튼은 원본 로그인 화면을 이용하도록 연결했습니다. 모든 기기와 모든 순간의 픽셀 단위 100% 일치를 보증하는 결과는 아닙니다.

원본에서 공개 제공하는 마크업·스타일·애니메이션 수치를 보존했습니다. 일부 React 구현은 원본에서 추출한 JSX runtime 형식을 유지합니다. 분석 자료는 `docs/research/`, 비교 화면은 `docs/design-references/`에 있습니다. 웹 분석/추적 코드는 포함하지 않았습니다.
